STAP 2: Tilemap.cs - De Grid Container

  📁 Locatie: Game/World/Tilemap.cs

  Wat moet je bouwen:
  class Tilemap
  ├── Properties
  │   ├── int Width, Height       → Grid afmetingen
  │   ├── Tile[,] tiles           → 2D array van tiles
  │
  ├── Constructor(width, height)  → Maakt lege grid
  ├── GetTile(x, y)               → Haal tile op positie op
  ├── SetTile(x, y, tile)         → Zet tile op positie
  ├── IsInBounds(x, y)            → Check of positie binnen grid is
  └── Fill(TileType type)         → Vul hele grid met 1 type

  Waarom hier:
  - Tilemap = collectie van tiles in een grid
  - Het is de "canvas" waarop je een kamer tekent
  - Het beheert alle tiles samen

  Wat je moet leren:
  - 2D Arrays → Tile[,] tiles = new Tile[width, height]
  - Nested loops → Door alle tiles itereren
  - Bounds checking → Voorkomen van array out of bounds errors
  - Indexing → tiles[x, y] toegang

  Voorbeeld logica:
  // Maak 20x15 grid
  for (int x = 0; x < width; x++)
  {
      for (int y = 0; y < height; y++)
      {
          tiles[x, y] = new Tile(x, y, TileType.Empty);
      }
  }

  STAP 3: RNGService.cs - Randomness Manager

  📁 Locatie: Services/RNGService.cs

  Wat moet je bouwen:
  class RNGService
  ├── Properties
  │   ├── Random random          → De random generator
  │   ├── int Seed               → De seed voor reproduceerbare dungeons
  │
  ├── Constructor(seed)          → Optioneel seed voor testing
  ├── Next(min, max)             → Random int tussen min en max
  ├── NextFloat()                → Random float 0.0 - 1.0
  ├── NextBool()                 → Random true/false
  └── PickRandom<T>(array)       → Kies random item uit array

  Waarom hier:
  - Service = herbruikbaar systeem door heel je game
  - Niet in World/ want het is geen wereld object
  - Centraal beheer van randomness = betere controle

  Wat je moet leren:
  - Seeded randomness → new Random(seed) voor dezelfde dungeons
  - Service pattern → Singleton of dependency injection
  - Generic methods → T PickRandom<T>(T[] array)
  - Extension methods → Later kan je array.PickRandom() maken

  Waarom belangrijk:
  Zelfde seed = zelfde dungeon
  Seed: 12345 → altijd dezelfde layout
  Perfect voor:
  - Testing
  - Shareable dungeons ("Try seed 99999!")
  - Speedrunning

  STAP 5: RoomGenerator.cs - De Magic!

  📁 Locatie: Game/World/RoomGenerator.cs

  Wat moet je bouwen:
  class RoomGenerator
  ├── Properties
  │   └── RNGService rng          → Voor randomness
  │
  ├── GenerateSimpleRoom()        → Rechthoekige kamer
  ├── GenerateCaveRoom()          → Cellular automata
  ├── GenerateCorridorRoom()      → Drunkard's walk
  └── PlaceExits(room)            → Zet deuren in muren

  ALGORITME 1: Simple Rectangle Room
  1. Maak tilemap
  2. Vul alles met Wall
  3. Maak binnen gebied Floor
  4. Plaats 1-4 doors in walls

  Pseudo-code:
  // Stap 1: Vul met walls
  for (x, y) in tilemap:
      SetTile(x, y, Wall)

  // Stap 2: Maak binnenruimte
  for x from 1 to width-1:
      for y from 1 to height-1:
          SetTile(x, y, Floor)

  // Stap 3: Plaats random door
  int doorX = random.Next(1, width-1)
  SetTile(doorX, 0, Door)  // Noord muur

  Wat je moet leren:
  - Procedural generation → Code maakt content
  - Algorithms → Stap-voor-stap instructies
  - Pattern filling → Grid vullen met patronen
  - Edge detection → Waar zijn de muren (randen)?

  STAP 6: Test in Game1.cs

  📁 Locatie: Game/Core/Game1.cs

  Wat moet je toevoegen:
  class Game1
  ├── In de class:
  │   ├── Room testRoom           → Test kamer
  │   ├── Texture2D tileTexture   → 1x1 pixel texture
  │   └── const int TILE_SIZE = 32
  │
  ├── In Initialize():
  │   ├── Maak RNGService
  │   ├── Maak RoomGenerator
  │   └── Genereer test room
  │
  ├── In LoadContent():
  │   └── Maak basic texture (wit vierkant)
  │
  └── In Draw():
      └── Teken alle tiles met kleuren

  Render logica:
  for (x, y) in tilemap:
      Tile tile = tilemap.GetTile(x, y)
      Color color = GetColorForType(tile.Type)

      Rectangle dest = new Rectangle(
          x * TILE_SIZE,
          y * TILE_SIZE,
          TILE_SIZE,
          TILE_SIZE
      )

      spriteBatch.Draw(tileTexture, dest, color)

  Kleuren per type:
  Wall   → Gray
  Floor  → DarkGray
  Door   → Brown
  Water  → Blue
  Pit    → Black

  Wat je moet leren:
  - SpriteBatch → MonoGame's 2D renderer
  - Texture rendering → Draw(texture, rectangle, color)
  - Coordinate mapping → Grid coords → pixel coords
  - Color tinting → Gebruik kleuren als placeholder sprites

  STAP 7: DungeonGenerator.cs - Multi-Room

  📁 Locatie: Game/World/DungeonGenerator.cs

  Wat moet je bouwen:
  class DungeonGenerator
  ├── GenerateLinearDungeon(roomCount)    → A-B-C-D chain
  ├── GenerateBranchingDungeon()          → Tree structure
  ├── ConnectRooms(room1, room2)          → Maak corridor
  └── PlaceRoomsOnGrid()                  → Spatial placement

  ALGORITME: Linear Dungeon
  1. Genereer 5 rooms
  2. Plaats ze in een rij (x: 0, 30, 60, 90, 120)
  3. Verbind elke room met de volgende
  4. Room 1 = start, Room 5 = boss

  Wat je moet leren:
  - Graph theory → Rooms = nodes, corridors = edges
  - Spatial algorithms → Niet-overlappende plaatsing
  - Pathfinding → Corridors tussen kamers
  - Procedural narrative → Start → Boss flow
